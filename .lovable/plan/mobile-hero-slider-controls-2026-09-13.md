# Mobile hero slider controls

## Scope
Adjust only the homepage hero slider controls and mobile spacing.

## Changes
- Remove the left and right navigation arrows.
- Add one accessible pause/resume icon control for the automatic slideshow.
- Keep slide-selection buttons available.
- Increase and stabilize the mobile slider height so text, actions, and slide selectors do not overlap.
- Preserve desktop layout, slide copy, images, routes, and existing styling.

## Verification
- Check the slider at the current mobile viewport and desktop width.
- Confirm no controls overlap and pause/resume stops and restarts automatic rotation.
- Confirm reduced-motion behavior and build status remain valid.
